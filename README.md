# Bayesian Virtual Surveys (BVS)

Implementation of **Bayesian Virtual Surveys (BVS)**, a probabilistic decision-support system for settings in which regulation precedes behavioural measurement.

Case study: acceptance of recycled plastic in food-contact packaging in Spain under EU Regulation 2025/40.

---

## What the system does

- Variables measured in the national survey (CIS Study 3391, ISSP Environment IV, Spain 2023, n = 2,254) are generated by a Bayesian network learned from those microdata alone, with a BDeu prior and survey-weighted counts (Martins et al., 2024).
- The outcome the survey does not measure (judging recycled plastic suitable for food packaging) is attached through a documented transfer model built from published coefficients (Ruokamo et al., 2022) and calibrated to a published base rate.
- External evidence from 11 studies is extracted with language-model assistance, reviewed, corrected through an explicit rules table, and summarised for the five candidate outcomes. Only food-packaging acceptance has evidence sufficient for a projection.

The synthetic population has 10,000 individuals (50 graphs from the structure posterior, 200 individuals each).

## Pipeline

| Script | Description | Main output |
|---|---|---|
| `step1.py` | Structure learning (block-wise parallel-tempered MC3); seed via `BVS_SEED` | `dag_edges_3391.csv`, `step1_mcmc_samples.json` |
| `step2.py` | Pooling of external evidence after `evidence_rules.csv` | `step2_dirichlet_priors.json`, `step2_input_mappings.json` |
| `evidence_table.py` | Evidence summary for the target outcomes | `target_evidence.csv` |
| `step3.py` | Conditional probability tables (legacy fusion; not used for the final population) | `step3_fused_priors.json` |
| `step4.py` | Synthetic population; S2 = network with BDeu prior and PESOFIN-weighted counts | `step4_output/synthetic_surveys_S2.csv` |
| `transfer_model.py` | Transfer model for food-packaging acceptance, intervals and sensitivity | `transfer_output/*.csv` |
| `transport_issp.py` | Finland-to-Spain transport error on ISSP 2020 proxy outcomes | `transport_output/issp_transport.json` |
| `transfer_transport.py` | Projections with empirical transport error | `transfer_output/transport_*.csv` |
| `measurement_plan.py` | Segment sensitivity to a0 and sample sizes for the first Spanish measurement | `transfer_output/segments_a0.csv`, `measurement_plan.csv` |
| `step4b_targets.py` | Attaches the target outcome to each synthetic individual | `step4_output/synthetic_surveys_final.csv` |
| `step6.py` | Fidelity and dependency diagnostics | `step6_output/` |
| `step8.py` | Baseline generators (CTGAN, TVAE, independent) | `step8_output/comparison_table.csv` |
| `step9.py` | Comparison with Ipsos 2022 Spain | `step9_output/ipsos_validation.json` |
| `make_figures.py` | Manuscript figures from pipeline outputs | `figures/*.png` |
| `app_gradio.py` | Query interface (ASAP v6) | |

Supporting modules: `harmonize_categories.py` (language-model-assisted extraction and scale harmonisation).

### Data files

| File | Content |
|---|---|
| `transfer_coefficients.csv` | Coefficients, standard errors, CIS coding and source of each predictor of the transfer model |
| `category_mappings.json` | Reviewed output of the language-model extraction (`harmonize_categories.py`): one entry per extracted item, with source, scale and statistics |
| `regression_priors.json` | Regression coefficients extracted from the external studies (used by the legacy `step3.py` only) |
| `evidence_rules.csv` | Corrections to extracted entries (exclusions, reversed items, re-expansion of single shares), with reasons |

ISSP 2020 Environment IV (ZA7650 v2.0.0, doi:10.4232/1.14153) must be downloaded from GESIS (registration required) and placed at `metadata/ZA7650_v2-0-0.dta`; it is not redistributed.

CIS Study 3391 microdata must be obtained from https://www.cis.es and placed at `metadata/3391_num.csv` (semicolon-separated, latin-1). The weight `PESOFIN` is stored with a decimal comma and is parsed accordingly.

## Usage

```bash
python step1.py
python step2.py
python evidence_table.py
python step4.py
python transfer_model.py
python measurement_plan.py
python transport_issp.py --issp metadata/ZA7650_v2-0-0.dta
python transfer_transport.py
python step4b_targets.py
python step6.py
python step9.py
python make_figures.py --base . --out figures
```

All random seeds are fixed at 42 unless set explicitly.

---

## Interpretation

Projections for food-packaging acceptance are scenarios conditional on transferred evidence (a Finnish base rate and Finnish effect sizes) and have not been validated in Spain. Synthetic individuals are computed from evidence; they are not observations and do not replace fieldwork or public engagement.
